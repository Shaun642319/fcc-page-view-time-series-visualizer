# Page View Time Series Visualizer

A time series data analysis project developed as part of the freeCodeCamp Data Analysis with Python certification.

This project analyzes daily page-view data from the freeCodeCamp forum to identify website traffic trends, seasonal patterns, and changes in engagement over time.

## Features
- Cleans time series data and removes extreme outliers
- Creates a line chart showing daily page views
- Generates monthly average page-view bar charts
- Uses box plots to analyze yearly trends and monthly seasonality
- Applies date-based grouping and aggregation

## Technologies
Python, Pandas, Matplotlib, Seaborn

## Dataset
freeCodeCamp forum daily page-view data
